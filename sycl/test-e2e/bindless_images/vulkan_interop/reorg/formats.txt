RECAP
=====

- --linear works 1D.  Fails everywhere else.  (low priority)
- 3D fails everywhere except 1x1x1.  (low priority)
- The format (channel count, data type) don't seem to matter too much. Tests pass or fail regardless.
- For 2D tests, the DIMENSIONS matter a lot. There are DEFINITELY problems as we cross the power-of-2 boundaries for height. 
  Surprisingly, not for Width. 
  Latest WORKING driver (ha) seems to work fine with 4 channel images, and has the "height not round" problem with 1 and 2 channel images.
- But, assuming the One Direction test passes, then adding a Semaphores works as well.
- 
- Semaphores fail utterly in the arithmetic tests. Driver cannot handle multiple semaphore dependencies. 
- sempaphores exhibit an addiitonal problem: if there is ANY failure (like using --linear or 3D) then all semaphore usage after that failure fails or hangs.


(*) One Direction Tests are Single Image, Data Handoff.

READ: Vulkan => hand off to SYCL.  Sampled and Unampled. 
WRITE: SYCL => Vulkan.     Unsampled Only 



(**) Arithmetic tests are Multi-Input, Single Output. ImageC = Image A + Image B. 

Pipeline:
- Vulkan: Uploads data to Image A. Signals SemA.
- Vulkan: Uploads data to Image B. Signals SemB.
- SYCL: Waits for both SemA and SemB.
- SYCL: Reads A and B, adds them, writes to Image C.
- SYCL: Signals SemC.
- Vulkan: Waits for SemC, reads back Image C.
